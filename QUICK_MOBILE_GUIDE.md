# Quick Mobile Guide - Three-Dots Menu

## What's New? 🎉

**On mobile phones (screen width ≤ 720px):**
- ✅ **Controls are now HIDDEN by default** - cleaner viewing experience
- ✅ **Three-dots button (⚫) in bottom-right** - tap to reveal controls
- ✅ **Auto-closes after use** - menu disappears after you select an option
- ✅ **Desktop unchanged** - normal controls still visible on larger screens

---

## 🔄 Landscape Mode

**When you rotate your phone to landscape:**

1. 📱 **Auto-fullscreen activates** (from previous feature)
2. ⚫ **Three-dots button still visible** (smaller, bottom-right)
3. 🎬 **Tap three-dots to access controls** if needed
4. 🔄 **Rotate back to portrait** - menu auto-closes

---

## ⚡ Quick Actions

### Open Menu
- **Tap** the three-dots button (⚫)

### Close Menu
- **Tap backdrop** (dark area around controls)
- **Tap any control** (auto-closes after 0.3 seconds)
- **Press ESC** (if you have a keyboard)
- **Rotate device** (auto-closes on orientation change)

## 💡 Tips

### Best Practices
- 🎯 **Keep menu closed** when just watching (cleaner view)
- 🔄 **Quick access** - tap three-dots anytime you need controls
- 📱 **One-handed use** - button positioned for easy thumb reach
- 🎬 **Landscape mode** - rotate for fullscreen, use three-dots for controls

### Shortcuts
- **Quick mute:** Tap three-dots → Tap mic → Auto-closes
- **Quick chat:** Tap three-dots → Tap chat → Auto-closes
- **Quick exit:** Tap backdrop or press ESC

## 🐛 Troubleshooting

**Q: I don't see the three-dots button**
- A: Check if your screen is ≤720px wide (mobile size)
- A: Try refreshing the page
- A: Clear browser cache

**Q: Menu won't open**
- A: Make sure you're tapping directly on the three-dots
- A: Check if you're in a live class (not join screen)
- A: Try force-refreshing the page

**Q: Menu stays open**
- A: Tap the backdrop (dark area) to close
- A: Press ESC key
- A: Tap any control button

**Q: Button in wrong position**
- A: This is normal - position adapts to screen size
- A: Should be bottom-right corner always
